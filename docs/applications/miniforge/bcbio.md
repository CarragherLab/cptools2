# bcbio

> **Source:** <https://www.wiki.ed.ac.uk/display/ResearchServices/bcbio>
> **GitHub:** <https://github.com/bcbio/bcbio-nextgen>

bcbio is a Python pipeline toolkit for automated high-throughput sequencing analysis.

> **Note:** The bcbio project was discontinued on 2024-08-16. It is now available on Eddie in a conda (miniforge) environment, as installation on Rocky Linux 9 is not possible from source.

## Loading bcbio

```bash
module load igmm/apps/miniforge/24.3.0
eval "$(conda shell.bash hook)"
conda activate bcbio.1.2.9
```
