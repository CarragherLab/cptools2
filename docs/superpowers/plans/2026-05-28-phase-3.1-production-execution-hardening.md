# Phase 3.1 Production Execution Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden the production cptools2 batching execution model so full workflows run from isolated Eddie scratch roots, preserve durable evidence, clean verified batches, and use a three-plate run as the first acceptance test.

**Architecture:** Keep Nextflow as the primary orchestrator and cptools2 as the owner of batching policy, launch contracts, cleanup gates, and user-facing evidence. Add explicit driver diagnostics modes and Eddie launch preflight support so scale runs can start reliably from `tmux` without shared `.nextflow` locks or unnecessary observer load.

**Tech Stack:** Python CLI (`argparse`, `subprocess`, `pathlib`, `json`, `csv`), pytest, Nextflow, Eddie SGE, tmux, rsync-backed stage-out verification.

---

## Scope

This plan extends Phase 3.1 beyond durable stage-out evidence into a production execution contract. The first runtime validation is the constrained three-plate Eddie run using real plates and verified cleanup.

Included:

- Configurable Nextflow diagnostics modes: `full`, `minimal`, and `off`.
- Run-local Nextflow launch isolation under the configured scratch output root.
- Eddie `tmux` launcher and preflight script generation.
- Stronger batch failure behavior so independent batches can continue when one batch fails.
- User-readable final run report for batch status, stage-out evidence, cleanup, and failures.
- Documentation for production launch and the three-plate acceptance ladder.

Excluded:

- Replacing Nextflow with native SGE scripts as the default route.
- Independent source/destination manifest verification after rsync.
- DINO model work.
- Optional Parquet memory redesign.

- Modify `cptools2/__main__.py`: diagnostics mode parsing, Nextflow command construction, batch loop failure handling, final report writing.
- Modify `tests/test_cli.py`: focused CLI tests for diagnostics flags, batch continuation, report output, and run-local command behavior.

```python
def _resolve_nextflow_diagnostics_mode(config, args):
    """Return the requested Nextflow diagnostics mode."""
    mode = getattr(args, "nextflow_diagnostics", None)
    if mode is None:
        mode = config.get("nextflow_diagnostics", "full")
    mode = str(mode).strip().lower()
    if mode not in {"full", "minimal", "off"}:
        raise ValueError(
            "nextflow_diagnostics must be one of full, minimal, or off; got {}".format(
                mode
            )
        )
    return mode


def _diagnostics_flags(mode):
    """Return Nextflow observer booleans for a diagnostics mode."""
    mode = str(mode).strip().lower()
    if mode == "full":
        return {
            "enable_trace": True,
            "enable_report": True,
            "enable_timeline": True,
        }
    if mode == "minimal":
        return {
            "enable_trace": True,
            "enable_report": False,
            "enable_timeline": False,
        }
    if mode == "off":
        return {
            "enable_trace": False,
            "enable_report": False,
            "enable_timeline": False,
        }
    raise ValueError("Unsupported diagnostics mode: {}".format(mode))


def _build_nextflow_command(
    nf_main,
    batch_params_path,
    batch_info,
    resume=False,
    diagnostics_mode="full",
):
    """Build the Nextflow command for one scratch-safe batch."""
    diagnostics_mode = str(diagnostics_mode).strip().lower()
    if diagnostics_mode not in {"full", "minimal", "off"}:
        raise ValueError(
            "diagnostics_mode must be one of full, minimal, or off; got {}".format(
                diagnostics_mode
            )
        )

    nf_cmd = [
        "nextflow",
        "run",
        nf_main,
        "-params-file",
        batch_params_path,
        "-profile",
        "eddie",
        "-work-dir",
        batch_info["batch_work_dir"],
    ]
    if diagnostics_mode in {"full", "minimal"}:
        nf_cmd.extend(["-with-trace", batch_info["trace_path"]])
    if diagnostics_mode == "full":
        nf_cmd.extend(["-with-report", batch_info["report_path"]])
        nf_cmd.extend(["-with-timeline", batch_info["timeline_path"]])
    if resume:
        nf_cmd.append("-resume")
    return nf_cmd
```

```python
def _run_report_path(output_dir):
    """Return the user-readable pipeline run report path."""
    return os.path.join(output_dir, "run_report.md")


def _write_run_report(output_dir, ledger_path):
    """Write a short Markdown report summarising batch outcomes."""
    rows = _load_batch_status_rows(ledger_path)
    report_path = _run_report_path(output_dir)
    os.makedirs(os.path.dirname(report_path), exist_ok=True)

    total = len(rows)
    failed = [row for row in rows if row.get("nextflow_status") == "failed"]
    cleaned = [row for row in rows if row.get("cleanup_status") == "cleaned"]
    stage_out_root = os.path.join(output_dir, "stage_out_evidence")

    lines = [
        "# cptools2 Pipeline Run Report",
        "",
        "Generated at: {}".format(_utc_now()),
        "",
        "Batch rows: {}".format(total),
        "Failed batches: {}".format(len(failed)),
        "Cleaned batches: {}".format(len(cleaned)),
        "Stage-out evidence: {}".format(stage_out_root),
        "",
        "| batch_name | plates | nextflow_status | stage_out_status | cleanup_status | message |",
        "|---|---|---|---|---|---|",
    ]
    for row in rows:
        lines.append(
            "| {batch_name} | {plates} | {nextflow_status} | "
            "{stage_out_status} | {cleanup_status} | {message} |".format(
                batch_name=row.get("batch_name", ""),
                plates=row.get("plates", ""),
                nextflow_status=row.get("nextflow_status", ""),
                stage_out_status=row.get("stage_out_status", ""),
                cleanup_status=row.get("cleanup_status", ""),
                message=str(row.get("message", "")).replace("|", "/"),
            )
        )
    lines.append("")

    with open(report_path, "w", newline="\n") as f:
        f.write("\n".join(lines))
    return report_path
```

Create `scripts/eddie_phase31_launch.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

if [[ $# -ne 4 ]]; then
  echo "Usage: $0 <project-root> <run-root> <config-yaml> <tmux-session>" >&2
  exit 2
fi

PROJECT_ROOT="$(cd "$1" && pwd)"
RUN_ROOT="$2"
CONFIG_YAML="$3"
SESSION_NAME="$4"

mkdir -p "${RUN_ROOT}"/{logs,traces,params,work,stage_out_evidence}

if [[ ! -f "${PROJECT_ROOT}/config/eddie_env.sh" ]]; then
  echo "Missing Eddie bootstrap: ${PROJECT_ROOT}/config/eddie_env.sh" >&2
  exit 1
fi

if tmux has-session -t "${SESSION_NAME}" 2>/dev/null; then
  echo "tmux session already exists: ${SESSION_NAME}" >&2
  exit 1
fi

cat > "${RUN_ROOT}/driver_status.json" <<JSON
{"status":"preparing","run_root":"${RUN_ROOT}","config":"${CONFIG_YAML}","session":"${SESSION_NAME}"}
JSON

{
  date -Iseconds
  hostname
  whoami
  pwd
  echo "ulimit_user_processes=$(ulimit -u)"
  echo "RUN_ROOT=${RUN_ROOT}"
  echo "CONFIG_YAML=${CONFIG_YAML}"
  echo "SESSION_NAME=${SESSION_NAME}"
  echo "PROJECT_ROOT=${PROJECT_ROOT}"
  echo "NXF_HOME=${RUN_ROOT}/.nxf_home"
  echo "python=$(command -v python3 || true)"
  echo "nextflow=$(command -v nextflow || true)"
  nextflow -version || true
  singularity --version || true
} > "${RUN_ROOT}/driver_env.txt"

qstat -u "${USER}" > "${RUN_ROOT}/qstat.before.txt" 2>&1 || true
ps -u "${USER}" -o pid,ppid,stat,comm,args > "${RUN_ROOT}/process_snapshot.before.txt" 2>&1 || true

cat > "${RUN_ROOT}/driver_command.sh" <<'DRIVER'
#!/usr/bin/env bash
set -euo pipefail

cd "${RUN_ROOT}"
source "${PROJECT_ROOT}/config/eddie_env.sh"
export PYTHONPATH="${PROJECT_ROOT}${PYTHONPATH:+:${PYTHONPATH}}"
export NXF_HOME="${RUN_ROOT}/.nxf_home"
export NXF_WORK="${RUN_ROOT}/work"
mkdir -p "${NXF_HOME}" "${NXF_WORK}"

cat > "${RUN_ROOT}/driver_status.json" <<JSON
{"status":"running","run_root":"${RUN_ROOT}","config":"${CONFIG_YAML}","session":"${SESSION_NAME}"}
JSON

set +e
python3 -m cptools2.__main__ pipeline "${CONFIG_YAML}" --cleanup-policy verified --continue-on-batch-failure --nextflow-diagnostics minimal > "${RUN_ROOT}/launcher.log" 2>&1
exit_code=$?
set -e

qstat -u "${USER}" > "${RUN_ROOT}/qstat.after.txt" 2>&1 || true
ps -u "${USER}" -o pid,ppid,stat,comm,args > "${RUN_ROOT}/process_snapshot.after.txt" 2>&1 || true

cat > "${RUN_ROOT}/driver_status.json" <<JSON
{"status":"finished","exit_code":${exit_code},"run_root":"${RUN_ROOT}","config":"${CONFIG_YAML}","session":"${SESSION_NAME}"}
JSON
exit "${exit_code}"
DRIVER

chmod +x "${RUN_ROOT}/driver_command.sh"

tmux new-session -d -s "${SESSION_NAME}" \
  "PROJECT_ROOT='${PROJECT_ROOT}' RUN_ROOT='${RUN_ROOT}' CONFIG_YAML='${CONFIG_YAML}' SESSION_NAME='${SESSION_NAME}' bash '${RUN_ROOT}/driver_command.sh'"

echo "Started tmux session ${SESSION_NAME}"
echo "Attach with: tmux attach -t ${SESSION_NAME}"
```

```markdown
## Eddie Production Driver Launch

For production-style Eddie runs, start the cptools2 Nextflow driver from a fresh
scratch run root inside `tmux`. Do not submit the driver itself with `qsub`,
because Eddie compute nodes are not submit hosts for child SGE jobs.

The driver run root must be unique per attempt and must be the current working
directory before invoking `cptools2 pipeline`. This keeps `.nextflow`, locks,
logs, and cache state local to the run instead of sharing state from the project
checkout.

Use `--nextflow-diagnostics minimal` for the first scale validation. This mode
must disable config-level report and timeline observers, not only omit CLI
`-with-report` and `-with-timeline` flags. Re-enable `full` diagnostics after
the three-plate acceptance run proves that the driver starts reliably on Eddie.
```
