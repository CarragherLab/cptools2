# Who Can Use Eddie

> **Source:** <https://www.wiki.ed.ac.uk/display/ResearchServices/Who+can+use+Eddie>

You must be connected to the University network to log into Eddie — either on a campus machine or connected to the University VPN.

## Eligibility

- **Staff:** Any member of staff can use Eddie without needing to request access. Log in using your University Username (UUN) and University Login/EASE password.
- **PhD candidates and research postgraduate students:** Can use Eddie without needing to request access, as above.
- **University visitors (UUN beginning with `v1`):** Should be able to use Eddie without requesting access, though a current bug in the provisioning script means this is not always the case. If you have a visitor UUN and are unable to access Eddie from within the University network, please contact the IS Helpline.
- **Taught course postgraduates:** Need to request access via their supervisor or PI, who must request access on their behalf using the appropriate form, providing: the student's UUN, module title, required access dates, and a brief outline of the computational component of the project.
- **Undergraduates:** Are not routinely given access to Eddie. In exceptional circumstances a project supervisor can request access if the project has a significant computational component. Requests must be made in good time and are not guaranteed.

## EASE Password Note

The EASE password is the password that works at <https://www.ease.ed.ac.uk/>. While it is standard practice for users to have the EASE password synced with the Office365/computer login (Active Directory) password, the EASE password is a separate password and in some cases — especially for older users — may not be the same as your Office365/computer login (AD) password.
