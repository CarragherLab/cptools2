## Problem Statement

After merging 4 parallel implementation lanes, a three-agent code review found 3 critical bugs (nonexistent function call, removed polars API, Nextflow type mismatch), 3 high-severity gaps (no publishDir, no --nv for GPU, missing stage name alignment), and 21 additional issues. Additionally, Lane A's more complete parse_yaml.py was overwritten during merge. All fixes must land on ai-update branch (no merge to master).

## Decisions Made

- **Canonical stage names**: `illum_calculate`, `illum_apply`, `segmentation`, `feature_extract` (matching Nextflow module labels and eddie.config)
- **Stage aliases**: `illum` -> `[illum_calculate, illum_apply]`, `segment` -> `[segmentation]`, `extract` -> `[feature_extract]`
- **Expanded names everywhere**: params.json writes expanded names, main.nf checks for expanded names. Users write short aliases in YAML, CLI expands them.
- **publishDir structure**: `output_dir/plate_id/stage_name/` (per-plate, per-stage)
- **Lane A merge-back**: Bring VALID_STAGES, resolve_stages(), join_files(), data_destination(), expanded valid_args into ai-update's parse_yaml.py
- **GPU/CPU label split**: Deferred. All current feature extraction tools use GPU.
- **Join CLI**: Auto-discovers plates from raw_data directory structure via `_discover_plates_from_raw_data()`

## Constraints

- All work on ai-update branch. No merge to master.
- 114 tests currently pass. Must not regress.
- parserix dependency stays (not abstracted yet).
- No new dependencies.

   ```python
   def _append_illum_columns(dataframe, illum_dir):
       df = dataframe._df if isinstance(dataframe, _CompatDataFrame) else dataframe
       # Detect channel numbers from existing FileName_W* columns
       channel_nums = []
       for col in df.columns:
           if col.startswith("FileName_W"):
               try:
                   num = int(col.replace("FileName_W", ""))
                   channel_nums.append(num)
               except ValueError:
                   pass
       for i in sorted(channel_nums):
           df = df.with_columns([
               pl.lit(f"illum_W{i}.npy").alias(f"FileName_Illum_W{i}"),
               pl.lit(illum_dir).alias(f"PathName_Illum_W{i}"),
           ])
       return _CompatDataFrame(df)
   ```
